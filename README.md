## 🧑‍🏫 Sobre mí

Soy profesor de **Formación Profesional de Informática** en el **IES Virrey Morcillo** (Villarrobledo). Imparto el módulo **Desarrollo de Interfaces** en 2º de **DAM** (Desarrollo de Aplicaciones Multiplataforma).

En este GitHub publico el material que preparo para mis alumnos: ejercicios resueltos, ejemplos comentados y proyectos documentados como se haría en una empresa, con manuales, API y control de versiones.

## 🎓 Para mis alumnos

> [!TIP]
> **¿Vienes de clase?** Clona el repositorio del tema, ábrelo en IntelliJ y ejecuta `Main.kt`. Cada proyecto tiene un **README** con los pasos y un **manual de usuario** en la carpeta `docs`.

| Si quieres… | Mira… |
|---|---|
| Repasar un ejercicio resuelto | El código de cada bloque, con comentarios que explican el porqué |
| Saber qué hace una función o clase | La **API** del proyecto, con buscador |
| Entender cómo está organizado un proyecto | El **manual técnico** |
| Aprender a usar Git y GitHub | El historial de commits de cada repositorio |
